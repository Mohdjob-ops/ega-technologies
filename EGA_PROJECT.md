# Elmi Guray Academy (EGA)

## Vision
Build a world-class technology academy that provides affordable education, AI training, web development, and opportunities for students, while creating a sustainable model that can also support students who cannot afford tuition.

---

## Technology Stack
- Expo SDK 56
- Expo Router
- React Native
- TypeScript
- Supabase
- EmailJS
- Chapa Payments
- Vercel
