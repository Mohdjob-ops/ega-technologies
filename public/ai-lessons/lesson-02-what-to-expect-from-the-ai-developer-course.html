Technical Explanation — English

This course is designed for developers who want to use artificial intelligence as part of their normal programming workflow.

The goal is not to remove the need for programming knowledge.

The goal is to combine:

  • Existing programming knowledge
  • Careful problem-solving
  • AI-powered development tools
  • Code review and testing

Students should learn how to use AI as an assistant instead of treating it as a replacement for the developer.

This Is Not a No-Code Course

A no-code course normally focuses on creating software without writing traditional code.

This EGA course is different.

Students will still need to understand programming concepts, read code, recognize errors, and test results.

AI may suggest code, but the developer remains responsible for the final decision.

Developer Responsibility

  • Understand the problem before asking AI for help.
  • Read generated code carefully.
  • Check whether the code matches the project.
  • Test the code before using it.
  • Correct unsafe, incorrect, or unnecessary code.

The course will explore several types of AI tools used by developers.

GitHub Copilot

GitHub Copilot is an AI-powered development assistant that can work inside supported code editors.

It may help with:

  • Completing code while the developer types
  • Suggesting functions or code blocks
  • Explaining code
  • Answering questions about a project
  • Supporting debugging

Students will also learn that AI suggestions may be incomplete, inaccurate, or unsuitable for the project.

Good developers do not accept every suggestion automatically.

Cursor IDE

Cursor is an AI-focused code editor.

An IDE or code editor is software used to write, organize, review, and test source code.

Cursor includes AI features directly inside the development environment.

This can make it easier to:

  • Ask questions about files
  • Request code changes
  • Review several parts of a project
  • Generate or improve code
  • Understand unfamiliar code

The course will help students understand when such features are useful and when manual review is still required.

ChatGPT for Developers

ChatGPT is not limited to code completion inside an editor.

It can support developers in situations such as:

  • Planning a new project
  • Comparing technical approaches
  • Explaining programming concepts
  • Creating documentation
  • Reviewing error messages
  • Preparing learning exercises
  • Discussing project structure

A general AI chatbot may be useful when the task is broader than writing one small piece of code.

Editor-Integrated AI and General AI

Different tools are useful for different tasks.

Tool Type Best Used For
Editor-integrated AI Working directly with source code, suggestions, files, and project context
General AI chatbot Planning, explanations, comparisons, documentation, and broader questions

A skilled developer learns how to choose the right tool for the current problem.

The Demo Project

The course will include a practical demonstration project.

The main purpose of the project is not to master one particular programming language.

Its purpose is to show how AI tools can support a real development process.

Students should focus on:

  1. How the problem is explained to the AI
  2. How suggestions are reviewed
  3. How errors are identified
  4. How code is tested
  5. How one tool may be chosen instead of another

The same ideas can later be applied to HTML, CSS, JavaScript, Python, Java, C#, or other programming languages.

Language Independence

AI-development skills are not limited to one programming language.

The exact syntax may change, but the main workflow is similar:

  1. Understand the task
  2. Give useful context
  3. Ask for focused assistance
  4. Review the response
  5. Test the result
  6. Improve the code

The Table Element

The <table> element displays information in rows and columns. 

<table border="1">

    <tr>
        <th>Tool</th>
        <th>Purpose</th>
    </tr>

    <tr>
        <td>GitHub Copilot</td>
        <td>Code assistance</td>
    </tr>

</table>

Important Table Elements

  • <table> creates the table.
  • <tr> creates a table row.
  • <th> creates a heading cell.
  • <td> creates a data cell.

Browser Output

The Article Element

The <article> element contains a complete piece of content that can stand on its own. 

<article>

    <h3>Developer Responsibility</h3>

    <p>
        Developers must review AI-generated code.
    </p>

</article>

The opening tag is <article>.

The closing tag is </article>.

It is useful for a complete lesson topic, news item, blog entry, or independent explanation.

The Emphasis Element

The <em> element gives emphasis to important words. 

<p>
    AI should <em>support</em> the developer.
</p>

Browser Output

AI should support the developer.

The opening tag is <em>.

The closing tag is </em>.

The Anchor Element

The <a> element creates a clickable link. 

<a href="#activity">
    Go to the Practice Activity
</a>

The href attribute tells the browser where the link should go.

The Image Element

The <img> element displays an image. 

<img
    src="ega-logo.png"
    alt="Elmi Guray Academy logo"
    width="180"
>
  • src contains the image location.
  • alt describes the image.
  • width controls the displayed width.

The image element does not use a closing tag.

Important Rules

  • Use AI together with programming knowledge.
  • Do not accept suggestions without reviewing them.
  • Choose the correct AI tool for the task.
  • Test generated code before adding it to a project.
  • Do not share passwords, API keys, or private data.
  • Focus on learning the workflow, not only copying code.
  • Ask focused questions with enough context.

Common Beginner Mistakes

  • Assuming every AI suggestion is correct
  • Asking a vague question without context
  • Copying code without understanding it
  • Using a general chatbot when project context is required
  • Using an editor assistant for a broad planning task
  • Forgetting to test the generated result
  • Believing one tool is best for every task

GAL — General Analogy Learning — English

Imagine a mechanic working in a garage.

The mechanic owns several tools:

  • A screwdriver
  • A wrench
  • A diagnostic computer
  • A lifting machine

The mechanic does not use the same tool for every job.

A wrench may be useful for one task, while a diagnostic computer may be better for another.

AI development tools work in the same way.

  • GitHub Copilot may help inside the code editor.
  • Cursor may help with project-wide coding tasks.
  • ChatGPT may help with planning and explanations.

The developer must understand the problem and choose the correct tool.
