Learning Objectives

By the end of this lesson, you should be able to:

  • Identify four important categories of AI tools used by developers.
  • Explain the difference between an external AI chatbot and a project-aware coding tool.
  • Explain how intelligent code completion works.
  • Describe what coding agents can do across multiple project files.
  • Explain how AI code-review tools support human reviewers.
  • Select an appropriate AI tool for a specific development task.
Central idea: AI development tools do not all perform the same job. A responsible developer must understand which tool category is suitable for each task.

English Technical Section

Developers now have access to several types of AI-powered tools. Although many of these tools use similar AI technology, they interact with developers and software projects in different ways.

The four important categories covered in this lesson are:

1

External AI Chatbots

External AI chatbots are general conversation tools. Developers can use them to ask questions, learn programming concepts, plan projects, analyze short code examples, and discuss possible solutions.

Examples mentioned in this course include:

ChatGPT Gemini

Good uses

  • Learning a programming concept.
  • Planning a new project.
  • Explaining an error message.
  • Discussing different solution ideas.
  • Generating a small example.

Main limitation

A normal external chatbot does not automatically know everything inside your local project.

It can only work with project information that you provide through your message, uploaded files, connected services, or another supported method.

2

AI Code-Completion Tools

Code-completion tools work inside or alongside a code editor. They examine the current file, nearby code, and other available context to predict what the developer may want to type next.

Examples covered in this course include:

GitHub Copilot Cursor

What makes the completion intelligent?

Traditional autocomplete may suggest a variable, method, or property from a known list.

AI-powered completion can often suggest:

  • A complete line of code.
  • A group of related lines.
  • An HTML structure.
  • A function based on its name or comment.
  • Code that matches the surrounding pattern.

The developer remains in control and decides whether to accept, modify, or reject each suggestion.

3

AI Coding Agents

A coding agent can perform work that is larger than a normal autocomplete suggestion.

Depending on its permissions and instructions, an agent may inspect the project, create files, update existing files, search for related code, run commands, and attempt to complete a multi-step development task.

Examples mentioned in the lesson include:

GitHub Copilot Cursor Claude Code

Possible agent tasks

  • Create a complete webpage.
  • Update several related files.
  • Find where a feature is implemented.
  • Repair a bug across a project.
  • Add a new component or route.
  • Run tests and react to test results.
Important: An agent can make changes quickly, but speed does not guarantee correctness. The developer must provide clear instructions and review every important change.
4

AI Code-Review Tools

AI code-review tools examine code changes and provide feedback before those changes are accepted into the main project.

They are commonly used with pull requests on platforms such as GitHub.

Examples mentioned in this lesson include:

BugBot CodeRabbit

What might they detect?

  • Possible bugs.
  • Missing error handling.
  • Security concerns.
  • Repeated code.
  • Unclear logic.
  • Possible performance problems.

Their feedback can give a human reviewer a useful starting point, but it should not automatically replace human judgment.

Example: Asking an External Chatbot

A developer could ask a general chatbot: 

Explain the difference between an HTML class and an HTML id.
Give me one simple example of each.

This question does not require the chatbot to understand an entire private project. It is a general programming question.

Example: Giving a Coding Agent Instructions

A developer could instruct a project-aware coding agent: 

Inspect the existing registration page.

Add a required preferred-language field with two choices:
English and Somali.

Keep the existing design.
Do not change the payment logic.
Show me the files you changed.

This request relates to a specific project. The agent needs access to the relevant project files and must understand how they work together.

Professional habit: Give coding agents narrow, clear, testable instructions. Review the result before moving to the next task.

Qaybta Farsamada ee Af-Soomaaliga

Qalabka AI ee ay developers-ku isticmaalaan dhammaantood isku shaqo ma qabtaan. Qaar waxay ku habboon yihiin su'aalaha guud, qaar waxay kaa caawiyaan qorista code-ka, qaarna waxay wax ka beddeli karaan mashruuc dhan.

1. Chatbot-yada AI ee Dibadda

Chatbot-yada dibadda sida ChatGPT iyo Gemini waxaa loo isticmaali karaa in lagu weydiiyo su'aalo, lagu barto fikradaha programming-ka, lagu qorsheeyo mashruuc cusub, ama lagu sharxo code yar.

Chatbot-ku si toos ah uma garanayo dhammaan faylasha mashruucaaga gaarka ah. Wuxuu ku shaqayn karaa keliya macluumaadka aad siisay ama aad u oggolaatay inuu arko.

Waxay ku fiican yihiin:

  • Barashada fikrad cusub.
  • Sharaxaadda qalad.
  • Qorshaynta mashruuc.
  • Samaynta tusaale yar.
  • Isbarbardhigga xalal kala duwan.

2. Qalabka AI Code Completion

Qalabkani wuxuu ka shaqeeyaa gudaha code editor-ka. Wuxuu eegaa code-ka ku dhow meesha aad joogto, dabadeedna wuxuu soo jeediyaa waxa laga yaabo inaad qorto marka xigta.

GitHub Copilot iyo Cursor waa tusaalooyin qalabkan ka mid ah.

Talooyinka la bixiyo waxay noqon karaan:

  • Hal eray ama variable.
  • Hal sadar oo code ah.
  • Dhowr sadar oo code ah.
  • Function dhammeystiran.
  • Qaab HTML ah oo ku habboon code-ka jira.

Developer-ka ayaa go'aaminaya inuu aqbalo, wax ka beddelo, ama diido talada.

3. Coding Agents

Coding agent-ku wuxuu qaban karaa hawl ka weyn code completion-ka caadiga ah.

Wuxuu baadhi karaa mashruuca, samayn karaa faylal cusub, wax ka beddeli karaa faylal badan, raadin karaa code la xiriira hawsha, mararka qaarkoodna wuxuu ordi karaa commands ama tests.

GitHub Copilot, Cursor, iyo Claude Code waxay tusaale u noqon karaan qalab leh awood agent.

Digniin: Agent-ku si degdeg ah ayuu wax u beddeli karaa, laakiin developer-ku waa inuu si taxaddar leh u hubiyaa isbeddellada ka hor inta aan la aqbalin.

4. Qalabka AI Code Review

Qalabka code review-ga wuxuu baarayaa isbeddellada lagu sameeyay code-ka. Badanaa wuxuu ka shaqeeyaa pull request la furay.

BugBot iyo CodeRabbit waa tusaalooyin lagu xusay casharkan.

Waxay soo sheegi karaan:

  • Bug suuragal ah.
  • Amni-darro suuragal ah.
  • Error handling maqan.
  • Code isku soo noqnoqday.
  • Logic aan caddayn.
  • Meel waxqabadku gaabis noqon karo.

AI review-gu wuxuu caawin karaa qofka code-ka eegaya, laakiin kama maarmin hubinta bini'aadamka.

Fikradda muhiimka ah: Dooro qalabka ku habboon hawsha aad qabanayso. Ha u isticmaalin hal nooc oo AI ah dhammaan shaqooyinka.

Tool Category Comparison

Category Main Purpose Project Awareness Typical Output Developer Responsibility
External AI Chatbot Answer questions, explain concepts, and support planning. Usually limited to information supplied or made available by the user. Explanations, suggestions, plans, and code examples. Provide enough context and verify the answer.
AI Code Completion Suggest what the developer may type next. Understands the current file and available surrounding context. A word, line, block, function, or repeated code pattern. Accept, modify, or reject each suggestion.
AI Coding Agent Perform larger, multi-step development work. Can inspect and operate across project files when access is provided. New files, edited files, commands, tests, and completed features. Give clear limits, inspect changes, and test the result.
AI Code Review Analyze code changes and suggest improvements. Focuses on the changed code and related context. Review comments, warnings, and suggested corrections. Decide which findings are correct and important.

Quick Decision Guide

I need a concept explained.

Start with an external AI chatbot.

I am typing code and want suggestions.

Use an AI code-completion tool.

I need several project files updated.

Use a coding agent with clear instructions.

I want feedback on a pull request.

Use an AI code-review tool together with human review.

GAL — English Analogy

Think of Building a House

Imagine that a software project is a house being built. Each AI-tool category has a different role.

External AI Chatbot = Consultant

A consultant can explain general building ideas, compare materials, and help you plan.

However, the consultant may not know the exact condition of your house unless you provide drawings, photos, measurements, and other details.

Code Completion = Skilled Assistant Beside You

This assistant watches the part you are currently building and prepares the next likely tool or material.

You still decide whether the suggestion is correct.

Coding Agent = Construction Team

A construction team can complete several connected tasks across different rooms.

The team needs clear plans, boundaries, supervision, and inspection.

Code Review Tool = Building Inspector

The inspector examines completed work and identifies possible safety or quality problems.

A human owner or engineer still makes the final decision.

Ka Fikir Dhisme Guri

Mashruuca software-ka waxaad u malayn kartaa guri la dhisayo. Nooc kasta oo qalabka AI ah wuxuu leeyahay shaqo u gaar ah.

Chatbot-ka Dibadda = La-taliye

La-taliyuhu wuxuu sharxi karaa fikradaha guud, wuxuu kaa caawin karaa qorshaynta, wuxuuna isbarbardhigi karaa xalal kala duwan.

Laakiin ma garanayo xaaladda gurigaaga haddii aadan siin sawirka, cabbirka, iyo qorshaha.

Code Completion = Kaaliye Kula Taagan

Kaaliyuhu wuxuu eegayaa qaybta aad hadda dhisayso, wuxuuna kuu diyaarinayaa waxa xiga ee laga yaabo inaad u baahato.

Adiga ayaa go'aaminaya inaad isticmaasho iyo in kale.

Coding Agent = Kooxda Dhismaha

Kooxdu waxay qaban kartaa shaqooyin badan oo isku xiran, xitaa qolal kala duwan.

Waxay u baahan tahay amar cad, xuduud cad, kormeer, iyo hubin.

Code Review = Kormeeraha Dhismaha

Kormeeruhu wuxuu eegayaa shaqada la dhammeeyay, wuxuuna sheegaa khaladaad ama khataro suuragal ah.

Qofka masuulka ah ayaa weli leh go'aanka ugu dambeeya.

Practical Activity

Read each situation and decide which AI-tool category is most appropriate.

Situation 1

A beginner wants to understand what an HTML form is and see one small example.

Show suggested answer

External AI chatbot.

This is a general learning question and does not require access to a complete project.

Situation 2

A developer is writing a function, and the editor predicts the next several lines.

Show suggested answer

AI code-completion tool.

The tool is predicting code from the current file and surrounding context.

Situation 3

A developer wants a tool to inspect the project, create a new page, add navigation, and update several related files.

Show suggested answer

AI coding agent.

The task requires project awareness and changes across multiple files.

Situation 4

A team opens a pull request and wants automatic feedback about possible bugs before a human review.

Show suggested answer

AI code-review tool.

The tool examines proposed code changes and adds review comments.

Instruction-Writing Practice

Improve the following unclear instruction: 

Fix my website.

A clearer instruction could be: 

Inspect the home page and find why the Register button
does not open the registration page.

Do not redesign the page.
Do not change the payment files.
Explain the cause before making changes.
After the change, tell me which file was updated.
Clear instructions reduce unnecessary changes and make AI-agent work easier to review.

Open Answer Key
  1. A — External AI chatbot
  2. B — Predicts and suggests code
  3. B — Updating connected project files
  4. A — Reviews code changes
  5. B — It may not have project access
  6. C — The developer or project team
  7. B — It may perform multi-step tasks
  8. B — Give clear instructions and review

Remember

  • External AI chatbots are useful for general questions, explanations, planning, and small examples.
  • Code-completion tools suggest code while you work inside the editor.
  • Coding agents can perform larger tasks and may change multiple project files.
  • Code-review tools inspect proposed changes and identify possible problems.
  • AI suggestions can be incorrect, incomplete, or unsafe.
  • The developer must provide context, set limits, inspect changes, and test the result.
  • Use the right AI-tool category for the right task.

Somali Remember

  • Code completion-ku wuxuu soo jeediyaa code markaad wax qorayso.
  • Coding agent-ku wuxuu qaban karaa hawlo waaweyn oo taabanaya faylal badan.
  • Code review tool-ku wuxuu baarayaa isbeddellada wuxuuna tilmaamaa khaladaad suuragal ah.
  • Developer-ku waa inuu hubiyaa, tijaabiyaa, oo maamulaa shaqada AI.
