Lesson Introduction

In Lesson 8, we introduced GitHub Copilot as an AI coding assistant.

In this lesson, we will focus more closely on how Copilot becomes part of a developer's working environment, how developers access it, why account authentication is required, and why subscription limits should be understood before depending heavily on AI coding tools.

We will use Visual Studio Code as our main example because it provides a common environment for learning AI-assisted software development.

Learning Objectives

By the end of this lesson, you should be able to:

  • Explain how GitHub Copilot connects to a development environment.
  • Understand the difference between an editor and an extension.
  • Identify important Copilot capabilities.
  • Understand why a GitHub account is required.
  • Understand why AI coding services may have usage plans and limits.
  • Recognize that pricing and plan details may change.
  • Understand the basic Copilot setup workflow.

Technical Explanation — English

1. Copilot Inside the Development Environment

GitHub Copilot adds AI-assisted development capabilities to supported coding environments.

Depending on the editor or IDE, Copilot may be available through an extension, integration, or built-in feature.

This means the developer does not always need to leave the coding environment to ask an AI tool for help.

2. What Is an Extension?

An extension is an additional software component that adds new capabilities to an existing application.

For example, Visual Studio Code can support extensions for:

  • Programming languages.
  • Debugging tools.
  • Formatting.
  • Git integration.
  • AI coding assistance.

An extension does not normally replace the editor. Instead, it adds functionality to it.

3. Main AI Capabilities

A Copilot-enabled development environment may provide several forms of AI assistance.

Capability Purpose
Code Completion Suggests code while the developer is typing.
Code Generation Generates code from an instruction or prompt.
AI Chat Lets developers ask questions about code and software problems.
Agentic Assistance Can attempt several related steps toward a development goal.

4. Code Completion

Suppose you start writing: 

function greetStudent(name) {

An AI coding assistant may predict the next part: 

function greetStudent(name) {
    return "Welcome, " + name;
}

This is called a code suggestion or code completion.

You should still understand the suggestion before accepting it.

5. Code Generation

Instead of starting the code yourself, you can also describe what you need.

Example prompt: 

Create a JavaScript function that checks
whether a quiz score is 70 or higher.

Possible generated code: 

function hasPassed(score) {
    return score >= 70;
}

6. AI Chat

AI chat provides a conversational way to work with the coding assistant.

You might ask: 

Explain this file.

Why am I getting this error?

How can I make this function easier to understand?

Write tests for this function.

Explain the difference between let and const.

7. AI Agents

More advanced AI coding systems may work in an agent-like way.

Instead of producing only one answer, an AI agent may attempt several related development steps.

For example: 

Create a registration form,
add validation,
check the existing project structure,
and explain the files you changed.

This type of assistance can be powerful, but the developer should review important actions before trusting the final result.

8. GitHub Account and Sign-In

GitHub Copilot is connected to GitHub services.

Therefore, the developer normally needs to authenticate with a GitHub account before using Copilot features.

Authentication means proving to the service which account you are using.

A typical flow may look like:

  1. Open Visual Studio Code.
  2. Open the Copilot feature or extension.
  3. Choose the sign-in option.
  4. Authenticate using your GitHub account.
  5. Return to the development environment.
  6. Confirm that Copilot features are available.

9. Plans, Usage Limits, and Cost

AI coding services can have different access plans and usage limits.

Some users may have limited access while heavier use may require a paid subscription.

The exact names, prices, limits, and available features can change over time.

Therefore, an AI Developer should never build permanent assumptions around an old price or plan name.

Always check the current official service information before paying for an AI development tool.

10. Usage Planning

Developers should think about how heavily they intend to use AI tools.

Occasional code assistance may require less usage than running AI agents frequently across a large software project.

This is one reason usage limits matter.

GAL — General Analogy Learning — English

Copilot Is Like Adding a Skilled Assistant to Your Workshop

Imagine a carpenter already has a workshop.

The workshop contains the table, tools, measurements, and materials needed for the job.

Instead of leaving the workshop every time help is needed, the carpenter brings a skilled assistant into the workshop.

The assistant can suggest the next cut, prepare material, or help solve a problem.

Copilot works similarly inside a development environment.

  • Workshop = IDE or code editor.
  • Carpenter = Developer.
  • Assistant = GitHub Copilot.
  • Instructions = Prompts.
  • Workshop membership/access = Account and subscription.

Practical Setup Example

A beginner developer can think of Copilot setup as this workflow:

  1. Install or open Visual Studio Code.
  2. Locate GitHub Copilot in the editor.
  3. Sign in with the correct GitHub account.
  4. Confirm your available Copilot access.
  5. Open a code project.
  6. Start with a small coding task.
  7. Review every suggestion before accepting it.

Example Prompt 

Create a simple HTML heading
for Elmi Guray Academy.

Possible Result 

<h1>
    Elmi Guray Academy
</h1>

Browser Output

Elmi Guray Academy

HTML Learning

The previous example introduced the <h1> element.

Opening tag: 

<h1>

Closing tag: 

</h1>

The <h1> element represents the main heading of a webpage or major content area.

It should be used according to document structure, not simply because you want large text.

Important Rules

  • Use your own GitHub account.
  • Never share your account password.
  • Understand what an extension is before installing it.
  • Review permissions requested by development tools.
  • Do not assume an old subscription price is still current.
  • Check current official plan information before paying.
  • Review AI-generated code.
  • Test AI-generated code before using it in production.

Common Beginner Mistakes

  • Assuming Copilot replaces Visual Studio Code.
  • Confusing an extension with the editor itself.
  • Signing in with the wrong GitHub account.
  • Forgetting that usage limits may exist.
  • Assuming pricing never changes.
  • Accepting every AI suggestion automatically.
  • Giving an AI agent broad access without understanding what it can change.
