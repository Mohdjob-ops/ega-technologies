EGA AI DEVELOPER COURSE — LESSON 11

Creating and Adding AI Images with Copilot in PowerPoint

Learn how to create AI-generated images using Microsoft Copilot, add them to PowerPoint, improve unclear results, and choose an effective slide design.

🎯 Learning Objectives

By the end of this lesson, you should be able to:
  • Open Copilot inside PowerPoint.
  • Ask Copilot to generate an image for a slide.
  • Write clear prompts for AI-generated images.
  • Improve a prompt when the first result is unsuitable.
  • Use PowerPoint Designer to improve the slide layout.
  • Create alternative images using Copilot on the web.
  • Save and insert AI-generated images into PowerPoint.

1. Creating Images with Copilot

Microsoft Copilot can do more than find and insert an existing picture. It can create a new image from a written description.

This can help when a slide has a small, unclear, unattractive, or unrelated image.

For example, a slide discussing local restaurant competition should use an image that clearly represents a restaurant or café. A small unrelated picture may not communicate the intended message.

Copilot may not understand every request correctly on the first attempt. Review the result and improve the prompt when necessary.

2. Opening Copilot in PowerPoint

Open the PowerPoint presentation and select the slide that needs an image.

Open Copilot from the PowerPoint toolbar. Copilot normally appears in a panel on the right side of the PowerPoint window.

You can choose one of Copilot's prepared editing prompts or type your own instruction directly.

Microsoft regularly updates PowerPoint and Copilot. Button names and locations may change, but the general image-generation process remains similar.

3. Removing an Unsuitable Image

Before generating a new picture, review the image already on the slide.

If it is too small, does not look professional, or does not match the slide's purpose, select and delete it.

Removing the unsuitable image creates space for Copilot to add the new image and allows PowerPoint Designer to suggest a cleaner layout.

4. Asking Copilot to Add an Image

In the Copilot panel, select an editing prompt for adding an image or type the request yourself.

A simple prompt could be: 

Add an image of a vegetarian restaurant.

Copilot will try to interpret the request and create an appropriate picture.

However, this instruction is broad. Copilot might generate a dining table, a vegetarian dish, or part of a restaurant instead of showing the complete restaurant.

5. When Copilot Misunderstands

Sometimes Copilot creates an attractive image that does not completely match the intended request.

For example, instead of creating a restaurant exterior, it may create an image of a table or a vegetarian meal.

The unexpected picture may still be useful on another slide. You can keep it for later and ask Copilot to try again.

An unexpected result does not always mean the feature failed. The prompt may simply need more detail.

6. Writing a Better Image Prompt

A strong image prompt should explain:

  • The main subject
  • The viewing position
  • The setting
  • The visual style
  • The intended use

A clearer prompt would be: 

Add an image of a modern vegetarian café viewed from the street.

An even stronger presentation prompt would be: 

Create a wide, realistic image of a welcoming vegetarian café viewed from across the street, with the entrance and sign visible, natural daylight, and space on the left for slide text.

This gives Copilot clearer information about the required subject, viewpoint, lighting, composition, and purpose.

7. Using PowerPoint Designer

After Copilot inserts an image, PowerPoint Designer may display alternative slide designs.

Designer can suggest different arrangements for:

  • The generated image
  • The slide title
  • The supporting text
  • The slide background and shapes

Choose a layout that keeps the image relevant and makes the slide text easy to read.

You can also resize or crop the image manually. Avoid stretching it because stretching damages its natural proportions.

8. Creating Images with Copilot on the Web

If Copilot inside PowerPoint does not create the image you need, you can use Copilot on the web.

Type an image-generation request such as: 

Create an image of a café viewed from the street in an Impressionist painting style.

Copilot may provide several images. Open the available options and choose the one that best supports your presentation.

An Impressionist image may contain soft details, blended colors, and visible painting-like textures. A photo style will appear more realistic, while a digital or 3D style will have a different visual appearance.

9. Saving and Inserting the Image

When you find a suitable image in Copilot on the web, save it to your device.

Return to PowerPoint and follow these steps:

  1. Open the required slide.
  2. Select the Insert tab.
  3. Select Pictures.
  4. Choose the saved AI-generated image.
  5. Insert the image into the slide.
  6. Resize, crop, and position it carefully.
  7. Confirm that the slide text remains readable.
You can create an image directly inside PowerPoint or generate it separately with Copilot on the web and insert it normally.

10. Practical Workflow

  1. Open the PowerPoint presentation.
  2. Select the slide that needs improvement.
  3. Remove the unsuitable image.
  4. Open Copilot.
  5. Request an AI-generated image.
  6. Review the result carefully.
  7. Rewrite the prompt if the result is unsuitable.
  8. Try Copilot on the web when necessary.
  9. Save and insert the best image.
  10. Use Designer or manual formatting to improve the layout.

11. English Technical Summary

  • Copilot can create images from written descriptions.
  • It can add generated images directly to PowerPoint slides.
  • Vague prompts may produce unexpected results.
  • Clear prompts describe the subject, viewpoint, setting, and style.
  • PowerPoint Designer can suggest improved slide layouts.
  • Copilot on the web provides another image-generation method.
  • Saved AI images can be added through Insert and Pictures.
  • The final image should support the slide's message.

13. Rules for AI-Generated Images

  1. Write clear and specific prompts.
  2. Explain the required viewpoint.
  3. Choose a style that matches the presentation.
  4. Review every image before using it.
  5. Do not accept an irrelevant image because it looks attractive.
  6. Keep slide text readable.
  7. Do not stretch or distort the image.
  8. Do not include confidential information in prompts.

14. Common Mistakes

  • Using a vague prompt such as “add a restaurant.”
  • Accepting the first image without reviewing it.
  • Failing to describe the required viewing position.
  • Using an image style that does not match the presentation.
  • Stretching or distorting the image.
  • Placing text over a busy part of the picture.
  • Using an attractive image that does not support the slide.
