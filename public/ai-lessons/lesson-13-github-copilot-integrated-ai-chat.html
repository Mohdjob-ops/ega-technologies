GitHub Copilot Integrated AI Chat

Learn how to open GitHub Copilot Chat, understand its different chat experiences, and organize it inside Visual Studio Code.

Introduction

Beyond AI Code Completion

GitHub Copilot can predict and complete code while you type. Its integrated AI chat provides a conversational way to work with artificial intelligence inside Visual Studio Code.

Copilot Chat lets developers ask questions, request explanations, investigate errors, discuss code, and plan improvements without leaving the development environment.

Main idea: Code completion suggests code while you type. Copilot Chat responds to natural-language questions and instructions.

Technical Lesson

Understanding Copilot Chat

1

What Is Integrated AI Chat?

Integrated AI chat is a conversational interface inside the development environment. It allows developers to communicate with GitHub Copilot without opening a separate AI website.

  • Ask for explanations of unfamiliar code.
  • Request help understanding errors.
  • Plan features before modifying a project.
  • Ask for suggestions to improve existing code.
  • Learn about programming languages and tools.
2

Three Copilot Chat Experiences

💬
Standard Chat A full conversation for connected technical questions and longer AI responses.
⌨️
Inline Chat Opens close to the code and works well with the current file or selected code.
⚡
Quick Chat A compact interface for short questions that do not require a permanent panel.
Chat type Best use Location
Standard Chat Long conversations Sidebar, editor, or separate window
Inline Chat Working directly with current code Inside the editor
Quick Chat Short questions Compact temporary interface
3

Opening Standard Copilot Chat

  1. Open Visual Studio Code.
  2. Confirm GitHub Copilot is installed and active.
  3. Select the Copilot or chat button near the top.
  4. Choose Open Chat.
  5. Enter a clear technical question or request.

Visual Studio Code may display a keyboard shortcut beside the command. Shortcuts can differ by operating system and version.

4

Using the Secondary Sidebar

Standard Copilot Chat commonly opens in the secondary sidebar. This keeps the conversation beside the main editor so you can read code and communicate with Copilot at the same time.

Hide the secondary sidebar when you need more coding space and reopen it when you want to continue the conversation.

5

Opening Chat in a Separate Window

Copilot Chat can be detached from Visual Studio Code and opened in a separate window. This is particularly useful when working with two monitors.

The code editor can remain on the first monitor while the Copilot conversation appears on the second monitor.

6

Moving Chat into the Editor Area

Chat can also be placed inside the editor area, where it behaves similarly to an open editor tab.

  • Use more width for long AI responses.
  • Keep the sidebar available for project files.
  • Switch between chat and code using editor tabs.
  • Read detailed technical explanations more comfortably.
There is no single correct layout. Choose the arrangement that best matches your screen size, monitors, and development task.
7

Chat and AI Agents

Standard Copilot Chat can support advanced workflows, including AI agents. An agent may work on broader tasks than simple code completion.

Inline chat and quick chat serve different purposes and will be explored separately.

Rules

Rules for Using Copilot Chat

  1. Describe the task and expected result clearly.
  2. Never assume every Copilot response is correct.
  3. Read and understand suggested code before accepting it.
  4. Test changes in a safe development environment.
  5. Never share passwords, keys, or private student information.
  6. Divide large requests into smaller, verifiable tasks.
  7. Remember that shortcuts vary by system and version.
Common Mistakes

Mistakes to Avoid

Confusing completion with chat

Completion predicts code while you type. Chat responds to questions and instructions.

Using an unclear request

“Fix it” provides too little context. Explain the problem and expected result.

Believing the sidebar is the only location

Chat can be moved into the editor or a separate window.

Accepting answers without testing

Copilot can produce incomplete or incorrect suggestions.

Sharing sensitive information

Never include passwords, private keys, or personal information.

Remember

Important Points

  • Copilot Chat is conversational: ask questions using natural language.
  • You control the layout: use the sidebar, editor, or a separate window.
  • Chat types have different purposes: standard, inline, and quick chat are not identical.
  • Clear instructions produce better assistance: provide context and the desired result.
  • You remain responsible: review and test all suggestions.
