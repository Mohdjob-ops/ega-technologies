Introduction

Two Faster Ways to Work with Copilot

GitHub Copilot provides Inline Chat and Quick Chat for developers who want assistance without keeping the full sidebar conversation open.

Main idea: Inline Chat is designed for targeted edits to selected code. Quick Chat is designed for short questions, explanations, and lightweight change requests.

Technical Lesson

Inline Chat and Quick Chat

1

Opening Inline Chat

Inline Chat can be opened from the Copilot controls or with the shortcut displayed by Visual Studio Code.

  1. Highlight the code you want Copilot to examine.
  2. Open Inline Chat.
  3. Describe the exact change you want.
  4. Send the request and review the proposed edit.
Example request Remove the unused variable from the selected code without changing the program’s behavior.
2

Selecting a Model and Adding Context

Copilot may allow you to select the AI model used for a request. Different models can vary in speed, reasoning, and availability.

You can also add relevant files, editor windows, or other available context. Context helps Copilot understand how the selected code relates to the rest of the project.

Add only context that is relevant. Never include passwords, API secrets, private student records, or other sensitive information.
3

Reviewing an Inline Edit

Copilot normally previews its proposed change instead of silently editing the code. Deleted code may be highlighted in red, while new code may use a different highlight.

  • Keep or Accept: apply the proposed change.
  • Reject or Deny: discard the proposed change.
  • Diff Editor: inspect complex changes carefully.
  • Undo: reverse an applied change when necessary.
4

When Inline Chat Is Most Useful

Inline Chat is best for targeted edits when you already know which code should be modified.

  • Remove an unused variable.
  • Rename a selected function.
  • Simplify a specific HTML section.
  • Add validation to a selected form field.
  • Explain or improve a highlighted block of code.
5

Opening Quick Chat

Quick Chat is a compact chat bar opened from the Copilot menu or its displayed shortcut. It is useful when you want a quick answer without switching away from the editor.

Quick Chat can use the currently open file as context. You may also select a model, add context, or move the conversation into the full sidebar chat.

6

Applying a Quick Chat Suggestion

When Quick Chat returns a code snippet, available actions may include:

  • Apply the change to the relevant file.
  • Insert the code at the cursor position.
  • Copy the code and paste it manually.
  • Insert an appropriate command into the terminal.
  • Open the conversation in the full Chat view.

After applying a change, inspect the preview and decide whether to keep or undo it.

7

Quick Questions and Explanations

Quick Chat is especially useful for asking what a program does, understanding unfamiliar code, or learning how to complete a task.

Example question What does this HTML and JavaScript program do? Explain its behavior in simple steps.

Some reasoning models may take longer because they analyze the request before producing the final response.

Practical Workflow

Make a Safe Targeted Edit

1
Select code Highlight only the code that needs attention.
2
Open Inline Chat Use the Copilot control or displayed shortcut.
3
Write a precise request State what should change and what must remain unchanged.
4
Review the preview Inspect deleted and added code before accepting it.
5
Test the result Confirm the page or program still behaves correctly.
6
Use Quick Chat Ask for an explanation when you need information rather than a direct edit.

Rules

Rules for Safe Copilot Chat Use

  1. Select only the code relevant to the requested change.
  2. Explain the intended result clearly.
  3. Provide only necessary and non-sensitive context.
  4. Review previews before accepting changes.
  5. Use the diff editor for larger modifications.
  6. Test every accepted change.
  7. Never share passwords, private keys, or student information.
Common Mistakes

Mistakes to Avoid

Selecting too much code

Unnecessary code can make the request less focused.

Giving an unclear instruction

Explain exactly what should change and what must remain unchanged.

Accepting changes without reviewing the preview

Inspect deleted and added code before applying it.

Using Quick Chat for a large project-wide task

Move complex work into the full Chat view when appropriate.

Failing to test the result

A reasonable-looking AI suggestion can still introduce errors.

Remember

Important Points

  • Inline Chat is targeted: select the relevant code first.
  • Quick Chat is lightweight: use it for short questions and explanations.
  • Context affects results: provide only useful, safe information.
  • Copilot proposes changes: you decide whether to accept them.
  • You remain responsible: understand and test every change.
