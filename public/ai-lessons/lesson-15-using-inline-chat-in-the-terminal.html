Technical Lesson

Terminal Inline Chat

1

What Is the Integrated Terminal?

The integrated terminal is a command-line area built into Visual Studio Code. It lets developers run project commands while keeping their source files visible.

2

Opening Terminal Inline Chat

  1. Open your project in Visual Studio Code.
  2. Open the integrated terminal.
  3. Right-click inside the terminal area.
  4. Select Open Inline Chat.

You may also use the keyboard shortcut displayed by Visual Studio Code. Shortcuts can differ by operating system and editor version.

3

Requesting a Command

Describe what you want to accomplish in clear language. Copilot can then suggest a suitable command for the active terminal.

Example request Show me the command that checks this Expo project for TypeScript errors without changing any files.

A suitable suggestion may be npx tsc --noEmit, but the command must still be reviewed before it is executed.

4

Review Before Running

  • Read the complete command carefully.
  • Understand which files or services it may affect.
  • Check paths, options, and command arguments.
  • Be cautious with installation and administrator commands.
  • Do not execute destructive commands you do not understand.

Rules

Terminal Safety Rules

  1. Confirm that the terminal is in the correct project directory.
  2. Ask Copilot for one clear task at a time.
  3. Understand every command before running it.
  4. Inspect file paths and command options carefully.
  5. Never paste passwords, tokens, or private keys into chat.
  6. Avoid destructive commands unless their effect is fully understood.
  7. Read the terminal output before continuing.
Common Mistakes

Mistakes to Avoid

Running a command without reading it

A suggested command can be incorrect or unsuitable for the project.

Using the wrong directory

A correct command may fail or affect the wrong project folder.

Ignoring command options

Options can substantially change what a command does.

Sharing secrets

Never provide passwords, access tokens, or private API keys.
