What to Expect from This Course

Approximate lesson time: 4–5 minutes

Lesson Goal

In this lesson, you will understand what this course will teach and how AI tools will support your programming skills.

English Explanation

This course is designed for students who want to use Artificial Intelligence while learning and practising programming.

It is not a no-code course. You will not depend on AI to do all the programming work for you.

Instead, you will combine your own programming knowledge with useful AI tools.

Your programming skills remain important because you must understand, review, test, and improve the code suggested by AI.

Tools You Will Explore

1. GitHub Copilot

You will learn how GitHub Copilot works inside a code editor.

You will explore features such as:

  • AI-powered code suggestions
  • Automatic code completion
  • Copilot Chat
  • Using comments as instructions
  • Reviewing and controlling suggestions
  • Avoiding common AI mistakes

2. Cursor

You will also learn about Cursor, a code editor designed with AI tools deeply included in the development experience.

You will understand how Cursor can help you read, change, explain, and organise code.

3. ChatGPT and Other AI Assistants

Some AI tools work outside the code editor. ChatGPT is one example.

These tools can help you:

  • Understand programming concepts
  • Ask questions about code
  • Plan a project
  • Find possible errors
  • Improve instructions and comments
  • Generate ideas before writing code

Learning When to Use Each Tool

Different AI tools are useful in different situations.

GitHub Copilot may be useful while you are actively writing code inside Visual Studio Code.

Cursor may be useful when you want an editor with AI features built deeply into the whole project.

ChatGPT may be useful when you want a longer explanation, a lesson, a project plan, or help understanding a difficult idea.

The goal is not to choose one tool for everything. The goal is to understand which tool is most helpful for each task.

Learning Through a Project

Later in the course, you will see how AI tools can support the development of a small project.

The most important part will not be the exact project code. The important part will be understanding the process:

  1. Describe what you want to build.
  2. Ask AI for useful guidance.
  3. Review the suggested code.
  4. Test the result in the browser.
  5. Find and correct mistakes.
  6. Improve the project step by step.

These skills can later be used with HTML, CSS, JavaScript, and other programming technologies.

TEC — Technical Understanding

TEC — English

AI tools can support different stages of software development.

  • Planning: AI can help organise ideas and project requirements.
  • Writing: AI can suggest HTML elements and complete repeated code.
  • Understanding: AI can explain unfamiliar code.
  • Debugging: AI can suggest possible causes of an error.
  • Improving: AI can suggest clearer structure or better wording.

AI is most useful when the developer provides clear instructions, reviews the output, and tests the final result.

GAL — Real-Life Analogy

GAL — English

Imagine a builder working with several assistants.

One assistant brings tools, another reads the plan, and another checks for mistakes.

The assistants make the work faster, but the builder must still understand the building plan and make the final decisions.

AI tools work in a similar way. GitHub Copilot, Cursor, and ChatGPT can help with different tasks, but the developer remains responsible for the project.
